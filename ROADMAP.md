# Roadmap

## Implemented foundation

- Broad language, framework, graphics library and preview catalog
- Flutter, SwiftUI, Compose and egui source renderers
- Tauri desktop renderer
- Figma exported JSON import
- OpenCV/Tesseract layout extraction
- OCR reading order and layout-grid anchors
- Tailwind mappings and React Tailwind source
- HTML and React/Vite renderers
- Responsive Chromium screenshots
- Browser DOM accessibility QA
- Pillow visual comparison
- Seamless base, normal and roughness texture export
- Neutral Three.js, Babylon, Unity, Godot, Unreal, Bevy and Blender manifests
- Signed manifest registry with target allowlist
- Git status, commit and push helpers
- Mnemosyne workspace handoff
- Semantic header/card/section/action inference
- Region-aware OCR pixel comparison
- Ed25519 plugin signing and verification
- Allowlist JSON/Python plugin sandbox
- GitHub CLI repository status and release helper
- Mnemosyne preview handoff
- Accessibility and responsive reports
- End-to-end mockup pipeline
